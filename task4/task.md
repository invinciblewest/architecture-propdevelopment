# Task4 \- RBAC в Kubernetes: роли и группы пользователей

| Роль                       | Права роли                                                                                                                                                                                                                                                                                               | Группы пользователей                                                                      |
|----------------------------|----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------|
| `platform-admin`           | Полный доступ ко всем ресурсам кластера: создание/изменение/удаление `namespaces`, `nodes`, `deployments`, `services`, `ingresses`, `configmaps`, `secrets`, `rbac`, `crds`; управление политиками безопасности и сетевыми политиками; доступ к логам и событиям                                         | Платформенная команда/DevOps/SRE                                                          |
| `namespace-admin`          | Администрирование в рамках одного `namespace`: управление `deployments`, `statefulsets`, `jobs/cronjobs`, `services`, `ingresses`, `configmaps`, `secrets`, `hpa`; просмотр логов/событий; без прав на `cluster-scoped` ресурсы и без управления `rbac` на уровне кластера                               | Тимлиды команд разработки/ответственные за сервисы                                        |
| `developer`                | Развёртывание и поддержка приложений в своём `namespace`: `get/list/watch/create/update/patch` для `deployments/statefulsets/jobs`, управление `pods` (кроме прямого `exec` при запрете политиками), чтение логов/событий, чтение `configmaps`; доступ к `secrets` только при необходимости (минимально) | Разработчики (backend/frontend), команда мобильного приложения при наличии backend\-части |
| `ops-support`              | Диагностика и поддержка: `get/list/watch` по ресурсам `namespace`, чтение логов и событий, просмотр метрик; без прав на изменение манифестов и без доступа к `secrets`                                                                                                                                   | Дежурная смена/2\-я линия поддержки/эксплуатация                                          |
| `security-auditor`         | Только чтение для аудита: `get/list/watch` по ресурсам, просмотр `rbac` привязок, событий, логов (если подключено централизованное логирование); без изменения ресурсов и без чтения чувствительных `secrets` (или только метаданные)                                                                    | ИБ/аудит (внутренние контролирующие группы)                                               |
| `ci-cd-runner`             | Деплой через пайплайны в целевые `namespace`: создание/обновление `deployments`, `jobs`, `configmaps`; чтение статуса `pods`; запрет на управление `rbac` и `cluster-scoped`; доступ к `secrets` только к нужным для деплоя                                                                              | CI/CD сервисные аккаунты (GitHub Actions/другая система), релиз\-инженеры                 |
| `analyst-readonly`         | Доступ только на чтение к сервисам и их статусам в выделенном `namespace` (например, BI/аналитика): просмотр `services/ingresses`, `pods` (статусы), `events`, базовых метрик; без доступа к `secrets`                                                                                                   | Бизнес\-аналитик, Аналитик BI                                                             |
| `accounting-readonly`      | Только чтение к ресурсам бухгалтерских сервисов (в своём `namespace`): статусы деплойментов/подов, события, логи приложения; без изменения конфигураций и без доступа к `secrets`                                                                                                                        | Бухгалтер                                                                                 |
| `product-support-readonly` | Просмотр статусов клиентских сервисов (витрины/мобайл\-шлюзы) и логов для разбора инцидентов; без прав на изменение и без доступа к `secrets`                                                                                                                                                            | Менеджер (если участвует в операционной поддержке), поддержка клиентских сервисов         |
